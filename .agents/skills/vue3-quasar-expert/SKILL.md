# `vue3-quasar-expert`

Expert assistance for building web and mobile interfaces using
Vue 3 Composition API and Quasar Framework (v2).

## Capabilities
- Scaffold Vue 3 SFCs (`<script setup lang="ts">`) with Quasar.
- Design responsive layouts with Quasar grid system and CSS utilities.
- Write type-safe Pinia stores and Vue Router 4 guards.
- Integrate Better Auth client authentication workflows.
