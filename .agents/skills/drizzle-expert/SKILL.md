# `drizzle-expert`

Expert skill for designing PostgreSQL database schemas
with Drizzle ORM and managing `drizzle-kit` migrations.

## Capabilities
- Scaffold Drizzle table schemas (`pgTable`) with proper
  column types, defaults, and foreign keys.
- Write type-safe Drizzle relational queries (`db.query`).
- Generate and apply database migrations via `drizzle-kit`.
- Optimize PostgreSQL indexes and query performance.
