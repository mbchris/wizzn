# `capacitor-expert`

Specialized assistance for building cross-platform mobile apps with
Capacitor v7 and Vue 3 / Quasar.

## Capabilities
- Configure `capacitor.config.ts` and native project targets.
- Integrate native device APIs (Camera, Push Notifications, Storage).
- Debug iOS Xcode and Android Studio build & sync issues.
- Handle safe area layouts and native status bar styling.
