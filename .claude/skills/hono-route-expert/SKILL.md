# `hono-route-expert`

Assists with Hono API route architecture, middleware
chaining, request validation, and service integrations.

## Capabilities
- Scaffold typed Hono routes with `@hono/zod-validator`.
- Integrate Better Auth session checking in route context.
- Implement Stripe checkout session and webhook handlers.
- Configure Nodemailer email triggers for API events.
