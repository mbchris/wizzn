# M5 Launch Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Store-ready v1: push reminders, offline audio (premium), account deletion + data export, settings/legal, polish, production TTS, TestFlight + Play internal track.
**Architecture:** Reminder selection is a pure function in `@wizzn/shared` (tested); the worker runs it on a pg-boss schedule and sends through a `PushSender` port (FCM HTTP v1 for Android, APNs HTTP/2 + `.p8` JWT for iOS — no Firebase SDK on iOS, see `docs/setup-consoles.md`). Offline audio reuses the existing `<audio>` player with local file URLs; completions made offline are queued and replayed with their original timestamp.
**Tech Stack:** M4 stack + `@capacitor/push-notifications`, `@capacitor/haptics`, `@capacitor/share`, `@capacitor/filesystem`, `@capacitor/browser`, `@capacitor/assets` (dev). No new server dependencies (JWT/HTTP2 via `node:crypto`/`node:http2`).
**Spec:** `docs/superpowers/specs/2026-10-09-wizzn-design.md` §1, §9, §10 · **UI:** `LAYOUT.md`

## Global Constraints
- Reminders: opt-in; one per local day max; only when the streak is at risk (no completion today) or, on Sunday, when the weekly goal is 1–2 units short; at the user's `reminder_time` ±5 min in their time zone; never 22:00–08:00.
- Invalid/expired push tokens (FCM `UNREGISTERED`, APNs 410) are deleted.
- Account deletion removes the user and all rows (FK cascade), RevenueCat subscriber alias stays with Apple/Google — UI must say "Abo separat im Store kündigen".
- Offline: premium only; max 20 units / 500 MB; offline completions replay with `completedAt` ≤ 72 h old, local date computed from that timestamp.
- Platform rules (CLAUDE.md): icons via `ICON_MAP`, iOS confirmations as action sheets, segmented controls for exclusive choices.

## Review Focus
- Time zone edges: reminder at 23:55 Berlin = 21:55 UTC; DST switch day (tested in shared).
- Two worker instances / rerun → no double reminder (`last_reminded_on` compare-and-set).
- Offline completion replayed twice → counted once (existing unique index); replayed after midnight → counts for the original day.
- Delete account while premium → entitlement row gone, store subscription untouched, clear warning shown.
- Feed stays kept-alive across tabs after all M5 changes (playback position survives tab switch).
